# 🎯 אלופי הטריוויה — מערכת טריוויה מרובת משתתפים (RTL)

אפליקציית טריוויה בזמן אמת בעברית מלאה (עד **30 שחקנים** במקביל), מבוססת **Node.js**, **Express** ו-**Socket.io**.

## ✨ תכונות עיקריות
- **מסך מנחה / תצוגה מרכזית (`admin.html`)**:
  - הצגת השאלה, טיימר חי עם אפשרות השהיה/המשך, ומונה תשובות בזמן אמת.
  - חשיפת התשובה הנכונה עם התפלגות בחירות וחלוקת הנקודות.
  - לוח תוצאות (Leaderboard) ופודיום מנצחים (🥇🥈🥉) בכל שלב ובסיום החידון.
  - כפתורי שליטה מלאים למעבר קדימה/אחורה בין שאלות ואיפוס המשחק.
- **התאמה אישית והעלאת מדיה מהמחשב**:
  - **כותרת ראשית**: העלאת תמונת באנר/לוגו מהמחשב ו/או עריכת כותרת טקסט ותת-כותרת.
  - **רקע מלווה לכל החידון**: העלאת תמונת רקע מהמחשב שמוצגת בכל שלבי החידון (אצל המנחה ואצל כל השחקנים) כולל שליטה בכהות המעטפת לקריאות מושלמת.
  - **תמונה לכל דף שאלה**: העלאת תמונה מהמחשב לכל שאלה בנפרד (דרך חלון ניהול השאלות או בכפתור מהיר ישירות ממסך השאלה).
- **מסך שחקן (`index.html`)**:
  - הזנת שם, הצטרפות מהירה ושמירת חיבור אוטומטית ברענון דף.
  - 4 כפתורי בחירה גדולים וברורים (**א, ב, ג, ד**) מותאמים לניידים ולטאבלטים.
  - **נעילת תשובה מיידית** לאחר בחירה והצגת **ניקוד אישי** מתעדכן בראש המסך.
- **מודל ניקוד ייחודי (תקציב 100 נקודות לשאלה)**:
  - לכל שאלה קופה קבועה של **100 נקודות** המתחלקת שווה בשווה אך ורק בין המשתתפים שענו נכון (לדוגמה: 4 צדקו ← 25 נק' לכל אחד; 1 צדק ← 100 נק').

## 🚀 הפעלה מהירה

### אפשרות א': לחיצה כפולה (Windows)
לחצו פעמיים על הקובץ **`start.bat`** שבתיקיית הפרויקט — השרת יופעל אוטומטית ויפתח את מסך המנחה בדפדפן.

### אפשרות ב': דרך שורת הפקודה (Terminal)
```bash
npm start
```

לאחר ההפעלה:
- **מסך מנחה / תצוגה מרכזית**: `http://localhost:3000/admin.html`
- **מסך שחקן**: `http://localhost:3000/index.html` (או כתובת ה-IP המקומית המוצגת על מסך המנחה כדי להתחבר מטלפונים וטאבלטים באותה רשת Wi-Fi).

## 📁 מבנה קובץ `questions.json`
הקובץ מכיל מערך שאלות אמריקאיות הניתן לעריכה גם ישירות מתוך ממשק המנחה (`🎨 עיצוב וניהול שאלות`):

```json
[
  {
    "question": "איזה כוכב לכת במערכת השמש מכונה 'כוכב הלכת האדום'?",
    "answers": ["נוגה", "מאדים", "צדק", "שבתאי"],
    "correctIndex": 1,
    "image": ""
  }
]
```
